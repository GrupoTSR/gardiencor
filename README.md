# Gardiencor

Landing page de links da Gardiencor, criada com HTML, CSS e JavaScript puro.

## Publicação

O projeto pode ser publicado gratuitamente pelo GitHub Pages. Depois, configure o domínio `www.gardiencor.com.br` nas configurações de Pages e no DNS do domínio.

## Personalização

- Edite o conteúdo de `index.html`.
- Adicione novos cartões de links dentro de `<nav class="links">`.
- Ajuste cores e tipografia em `styles.css`.
